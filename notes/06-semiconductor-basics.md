# 電子學筆記：半導體材料基本介紹

## 1. 本質半導體：電子–電洞對

**熱激發**：室溫（300K）下，少數價電子吸收熱能，掙脫共價鍵。

|名詞|意義|
|-|-|
|價電帶（Valence band）|被共價鍵束縛的電子所在的能量範圍|
|導電帶（Conduction band）|自由電子所在的高能量範圍，可隨電場移動形成電流|
|能隙 E\_G（Band gap）|兩帶之間的能量差，矽 **E\_G = 1.12 eV**|

**重點**

* 一個電子躍遷 ＝ 產生 **一個電子＋一個電洞**（成對）。
* 所以本質半導體：導電帶電子濃度 ＝ 價電帶電洞濃度。

**兩種載子（carrier）**：導電帶的電子（濃度 **N**，Negative）、價電帶的電洞（濃度 **P**，Positive）。單位：cm⁻³。

\---

## 2. 本質載子濃度 Nᵢ

* 矽原子密度：約 5×10²² cm⁻³。
* 室溫 300K：**Nᵢ = Pᵢ ≈ 1.5×10¹⁰ cm⁻³**。
* 遠小於原子密度 → 純矽導電性差 → 「半導體」。

**溫度關係式**

> **$Nᵢ² = B · T³ · exp( −E\_G / kT )$**

* B：材料常數；k：波茲曼常數；T：絕對溫度。
* 溫度上升 → 指數項變大 → Nᵢ 暴增。
* **半導體元件特性與溫度強相關**（重要）。

\---

## 3. 熱平衡與質量作用定律

* 熱平衡下載子濃度加下標 0：N₀、P₀。

> **$N₀ · P₀ = Nᵢ²$**　（本質、外質半導體都成立）

**Nᵢ 與 N₀ 的差別**

* Nᵢ：本質半導體專屬的濃度常數（只跟材料、溫度有關）。
* N₀：任何半導體在熱平衡下的電子濃度（隨摻雜改變）。
* 本質半導體是 N₀ ＝ Nᵢ 的特例。

\---

## 4. 摻雜（Doping）

* **雜質（Impurity）**：與半導體本身不同的元素，並非壞東西。
* **摻雜（Dope）**：加入雜質的動作；**摻雜物（Dopant）**：加入的雜質。
* 加了摻雜物 → **外質半導體（Extrinsic）**。
* 目的：提高載子濃度、增加導電率。
* 摻雜後整塊半導體仍是**電中性**。

\---

## 5. N 型與 P 型對照（核心表格）

||**N 型**|**P 型**|
|-|-|-|
|摻雜物|五價：磷（P）、砷（As）|三價：硼（B）|
|名稱|**Donor**（施體，給電子）|**Acceptor**（受體，接受電子）|
|摻雜濃度|N\_D|N\_A|
|每個原子貢獻|1 個自由電子（第 5 顆價電子）|1 個電洞（第 4 個鍵缺電子）|
|另一種載子是否同時增加|否（沒有電洞產生）|否（沒有電子產生）|
|固定離子（空間電荷，不可移動）|N\_D⁺（核心 +5Q ＋ 4 電子 ＝ **+Q**）|N\_A⁻（核心 +3Q ＋ 4 電子 ＝ **−Q**）|
|多數載子（熱平衡）|電子 N\_N0 ≈ N\_D|電洞 P\_P0 ≈ N\_A|
|少數載子（熱平衡）|電洞 P\_N0 ≈ Nᵢ² / N\_D|電子 N\_P0 ≈ Nᵢ² / N\_A|
|名稱由來|N ＝ 多數載子電子（Negative）|P ＝ 多數載子電洞（Positive）|
|整體電性|電中性|電中性|

* 典型摻雜濃度：10¹⁵ ～ 10²⁰ cm⁻³，遠大於 Nᵢ。
* 室溫下摻雜物**完全解離**：N\_D⁺ ＝ N\_D，N\_A⁻ ＝ N\_A。
* 電荷中性：N 型 N\_N0 ＝ N\_D⁺ ＋ P\_N0；P 型 P\_P0 ＝ N\_A⁻ ＋ N\_P0。

**數字例（N\_D = 10¹⁶ cm⁻³）**

* 電子 ≈ 10¹⁶ cm⁻³
* 電洞 ≈ (1.5×10¹⁰)² / 10¹⁶ ≈ 2.25×10⁴ cm⁻³（差 12 個數量級）

## 6. 符號規則

以 **N\_N0**、**P\_P0** 為例，由左到右讀：

1. 第一個字母：載子種類（N 電子／P 電洞）
2. 下標第一位：所在半導體類型（N 型／P 型）
3. 下標 0：熱平衡（非熱平衡則省略）

\---

## 7. 重點公式

1. N₀ · P₀ = Nᵢ²
2. Nᵢ² = B · T³ · exp(−E\_G / kT)
3. N 型：N\_N0 ≈ N\_D，P\_N0 ≈ Nᵢ² / N\_D
4. P 型：P\_P0 ≈ N\_A，N\_P0 ≈ Nᵢ² / N\_A

## 8. 易混淆提醒

* 電洞（會移動的等效 +Q）≠ 摻雜離子（N\_D⁺、N\_A⁻，固定不動）。
* 本質半導體電子電洞成對；摻雜產生的載子**不成對**。
* 少數載子雖少但不為零，之後 PN 接面、二極體、電晶體會用到。
