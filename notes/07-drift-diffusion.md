# 電子學筆記：半導體內的電流機制（漂移與擴散）

## 0. 先備知識（上回複習）

- 載子：導電帶的電子（濃度 n，帶 −Q）與價電帶的電洞（濃度 p，等效 +Q），兩者可移動；空間電荷（$N_D$⁺、$N_A$⁻）固定不動，不貢獻電流。
- 質量作用定律：n₀·p₀ = nᵢ²，nᵢ ≈ 1.5×10¹⁰ cm⁻³（矽，300 K）。
- 摻雜：N 型（Donor）n ≈ $N_D$；P 型（Acceptor）p ≈ $N_A$；摻雜濃度常見 10¹⁵～10²⁰ cm⁻³。

## 1. 電流與兩種驅動機制

電流 = 電荷的流動。要讓載子流動需要驅動力，有兩種：

|  | 驅動力 | 名稱 |
| --- | --- | --- |
| 漂移 | 外加電場 $ℰ$ 推動載子 | 漂移電流 Drift current |
| 擴散 | 載子濃度不均，由濃往淡處擴散 | 擴散電流 Diffusion current |

## 2. 漂移電流（Drift Current）

**情境**：半導體兩端接電壓源 V，內部產生向右的電場 ℰ。

- 電洞（+）順著電場方向，向右移動。
- 電子（−）受力與電場反向，向左移動。
- 但電子往左 = 電流往右，所以兩種載子的漂移電流方向相同，會相加。

**漂移速度與遷移率 μ（Mobility）**

- 實驗：漂移速度正比於電場。
- 電洞：$v_p = μ_p·ℰ$
- 電子：$v_n = −μ_n·ℰ$（負號代表與電場反向）
- μ 的意義：每單位電場能換到多少速度，代表載子受電場後的移動能力。
- 矽的數值：μ_p ≈ 480 cm²/(V·s)，μ_n ≈ 1350 cm²/(V·s)。電子較好動（等效質量較輕，屬固態物理範疇）。

**電流密度推導**

- 面電流密度 $J = ρ·v$（ρ 為體電荷密度，單位 C/cm³；J 單位 A/cm²）。
- 電洞：$ρ_p = Q·p → J_{p,drift} = Q·p·μ_p·ℰ$
- 電子：$ρ_n = −Q·n$，$v_n = −μ_n·ℰ$，兩負號相乘為正 → $J_{n,drift} = Q·n·μ_n·ℰ$

**總漂移電流與導電率**

- $J_{drift} = Q·(μ_p·p + μ_n·n)·ℰ = σ·ℰ$
- **導電率 $σ = Q·(μ_p·p + μ_n·n)$**（單位 S/cm），電阻率 = 1/σ
- $J = σℰ$ 就是歐姆定律的材料版。
- 重點：σ 由 n、p 決定，而 n、p 可用摻雜控制，所以摻雜是調整半導體電阻的方法。

**數字感受**（Q = 1.6×10⁻¹⁹ C）

- 本質矽：n = p = 1.5×10¹⁰，σ ≈ 4.4×10⁻⁶ S/cm
- N 型，$N_D$ = 10¹⁶：$σ$ ≈ $Q·μ_n·n$ ≈ 2.2 S/cm，約為本質矽的 50 萬倍。

## 3. 擴散電流（Diffusion Current）

**基本觀念**：載子永遠從高濃度往低濃度擴散，電流密度與電荷濃度梯度成正比，電流方向要依電荷正負判斷。

**擴散常數 D（Diffusion constant）**

- 描述同樣濃度梯度下的擴散能力，單位 cm²/s，D 越大擴散越快、電流越大。
- 矽的數值：$D_p$ ≈ 12 cm²/s，$D_n$ ≈ 34 cm²/s。

**電洞**

- 梯度為負、電流為正，兩者異號，公式需要負號。
- $J_{p,diff} = −Q·D_p·\dfrac{dp}{dx}$

**電子**

- 梯度為負、電流為負，兩者同號，公式不加負號。
- $J_{n,diff} = +Q·D_n·\frac{dn}{dx}$

**總擴散電流**：$J_{diff} = Q·D_n·\dfrac{dn}{dx} − Q·D_p·\dfrac{dp}{dx}$（不能提公因式，因為符號不同）

## 4. 總電流公式

漂移與擴散可同時存在，直接相加：

- $J_n = Q·n·μ_n·ℰ + Q·D_n·\dfrac{dn}{dx}$

- $J_p = Q·p·μ_p·ℰ − Q·D_p·\dfrac{dp}{dx}$

- **$J_{total} = J_n + J_p$**

## 5. 愛因斯坦關係式（Einstein Relationship）

μ 與 D 的物理源頭相同（載子的熱運動與被晶格散射），所以兩者並不獨立：

- **$\dfrac{D_n}{μ_n} = \dfrac{D_p}{μ_p} = \dfrac{kT}{Q} = V_T$**

- $V_T = \dfrac{kT}{Q}$ 稱為**熱電壓**（Thermal voltage），與溫度成正比。
- 300 K 時 $V_T$ ≈ 25.9 mV（k = 1.38×10⁻²³ J/K）。
- 驗證：$\dfrac{D_n}{μ_n}$ = 34/1350 ≈ 25.2 mV；D_p/μ_p = 12/480 = 25.0 mV。
- 用途：知道 μ 就能算 D（D = μ·V_T），反之亦然。

## 6. 重點總整理

|  | 漂移（電場推） | 擴散（濃度不均推） |
| --- | --- | --- |
| 電洞 | $Q·p·μ_p·ℰ$ | $−Q·D_p·\dfrac{dp}{dx}$ |
| 電子 | $Q·n·μ_n·ℰ$ | $+Q·D_n·\dfrac{dn}{dx}$ |
| 能力參數 | 遷移率 μ | 擴散常數 D |
| 矽（數值） | $μ_p$ ≈ 480、$μ_n$ ≈ 1350 | $D_p$ ≈ 12、$D_n$ ≈ 34 |

**其他公式**

- 導電率 σ = Q·(μ_p·p + μ_n·n)，電阻率 = 1/σ
- 愛因斯坦關係：D/μ = kT/Q ≈ 25.9 mV（300 K）

**三個最容易搞混的地方**

1. 擴散時，電洞公式有負號，電子公式沒有。
2. 電流方向的定義永遠是正電荷移動的方向，所以電子的電流方向與其移動方向相反。

**單位檢查**

- 速度 cm/s = μ（cm²/(V·s)）× ℰ（V/cm）
- 電流密度 A/cm² = ρ（C/cm³）× v（cm/s）
